Automated Color-Sorting Manipulator Robot

Abstract

Developed a LEGO Mindstorms EV3-based automated pick-and-place and color-sorting system integrated with a conveyor belt. The system combines mechanical components, electric motors, sensors, encoders and control algorithms to identify and sort colored objects into predefined stations.

Implemented inverse kinematics using a geometric approach and programmed the robot using EV3 MicroPython. Sensor-based control and PID concepts were applied to coordinate manipulator movements and automated sorting operations.

System Components

Manipulator: Three electric motors with encoders for joint movement.

Conveyor: Motor-driven conveyor system for transporting objects.

Sensors: Color sensor for object detection and touch sensors for joint homing and motion limits.

Mechanical Structure: Five-link serial articulated manipulator.

Control System: Sensor-based control, encoder feedback and PID concepts.

Key Features

Automated color detection and sorting.

Pick-and-place operations using a robotic manipulator.

Geometric inverse kinematics for positioning.

Encoder-based position feedback.

Coordinated conveyor and manipulator operation.

Technologies Used

Project Objective

To demonstrate the integration of mechanical systems, electronics, sensors and software in an automated robotic application.
